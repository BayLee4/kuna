Raw recursive machine-effect closure — draft interface, no production edits

Goal: close actual residual direct-call SCCs (including recursive_inline collatz), without declaring an active recursion cut complete, replacing the actual owner body, or weakening publication.

1. Graph/lifetime
PhysicalInputDrive retains each actual mapped raw probe Funcdata for the current flow epoch while discovering children. It already limits discovery to32 and records active cuts. Root is the borrowed actual Funcdata, including request-local flow overrides; never re-lift root as an unoverridden probe. Build address-keyed adjacency from genuine CALL/callspec target addresses and exact member-local OpIds. Compute SCCs, leaves first. Indirect/unresolved/external-incomplete calls, bad/unimplemented/artificial-halt CFGs, unresolved indirect branches and discovery limits keep the SCC unresolved. Nonrecursive members retain existing analysis. No global cache or cross-epoch reuse.

2. Private domains, not provisional EntryRequirements
RawMayEffects: bytewise may-writes + reads_memory/writes_memory. Positive actual raw effects are monotone unions over the original local CFG and called members.
FiniteReturns: NoFiniteReturn | Returning { definite_writes, restored, stack_adjustments }. NoFiniteReturn means no finite returning execution has yet been constructed by this solver; it does NOT mean an unknown call or an ABI noreturn assertion. Internal call continuations are admitted only after the target has Returning facts. Real normal RETURNs in the actual CFG ground the induction. Facts meet across all finite normal returns as new returning call paths enter. A register restoration fact is about the fixed whole-SCC may-write universe, not a temporarily smaller write set. Stack deltas meet by exact equality; disagreement becomes unknown. External committed complete children use their actual raw effects. No conditional/native/deferred/generated family premises participate.
RawDemand: original read-before-def bytes, computed only after return facts stabilize. May-demand grows via child demand and uses now-stable definite writes as kills. Reads on prefixes of infinite recursion remain in the domain; non-returning internal calls stop only their following continuation. This phase ordering avoids keeping false incoming-result demands caused by an initially empty callee must-write set.

3. Shared solver interface
Introduce a private borrowed RawCallView over either committed complete EntryRequirements or RecursiveSnapshot. It exposes raw reads/maywrites/memory and finite-return facts, but has no is_complete boolean and cannot be stored on FuncCallSpecs/FD/publication. A RecursiveSnapshot is never converted into EntryRequirements before the entire SCC stabilizes. Ordinary analyze_flow/restore paths retain current incomplete handling. Dedicated recursive entry points reuse the same register-byte access extraction and raw transfer semantics with an explicit finite-return frontier, separate from ConditionalFlowView (readonly branch receipts are not reused for recursion).
Return-frontier handling must stop operations after a NoFiniteReturn call, prevent its block from feeding CFG successors, and still record prefix accesses. Restoration's block fixedpoint and final RETURN scan both use this same frontier. No vacuous restored/definite-write guarantees when no normal return exists.

4. Restoration restrictions
Existing actual raw COPY/arithmetic/LOAD/STORE provenance and call transfer are reused. Calls with raw memory effects conservatively invalidate saved stack origins exactly as today; no recursive private-frame promise or invented memory footprint. This may refuse recursive saved-register bodies that require a richer interprocedural footprint, but cannot fabricate their preservation. Collatz's actual frame path needs SP delta rather than a saved-register memory restoration proof; this remains unverified.

5. Completion/install
After stable may-effects, grounded finite-return facts and demand, validate every local CFG/call edge still matches the captured actual member graph. Only then materialize each SCC member's EntryRequirements with complete raw effects and no invented ExecutionRequirements. Install all member rawRc objects and mapped witnesses atomically into the flow-epoch cache, then bind actual root callsites and target map to those exact Rcs. Recompute dependent acyclic ancestors whose previous summary contained the cycle cut. Failed SCCs retain their original incomplete cut summaries. Publication uses ordinary complete-raw families/body providers; no new wire category, no deferred-cycle permission and no C-execution waiver.

6. Required validation
Actual host recursive_inline collatz unchanged bytes/prototypes/inlining/overrides must individually export and execute unchanged C at O0/O2; inspect complete original raw summary and actual selfCALL. Mutually recursive actual bodies with grounded return paths exercise more than self-only recursion. Unresolved member/external call, artificial halt, no grounded normal return and changed/missing provider must refuse rather than become empty-complete. Existing acyclic raw, readonly conditional, internal-role, generated/native and same-PID reflow cases must retain results.
